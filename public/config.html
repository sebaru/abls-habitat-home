Configuration manquante

⚠ Le fichier js/config.js est absent ou non configuré.

Ce fichier est nécessaire pour connecter la console à votre serveur d'authentification Keycloak.

Pour l'initialiser, copiez le fichier d'exemple et adaptez les valeurs à votre installation :

cp js/config.js.sample js/config.js
var $ABLS_API      = "https://api.votre-domaine.com";
var $IDP_REALM     = "abls-habitat";
var $IDP_URL       = "https://idp.votre-domaine.com";
var $IDP_CLIENT_ID = "abls-habitat-console";
Accéder à l'application
